# Financial Accounting System (Notion + Claude)

## Purpose
This repository manages the internal financial accounting system.

The system is designed to:
- Maintain financial rules (P1–P7)
- Adapt to legal changes
- Support Notion-based documentation
- Enable Claude to rebuild the system efficiently

---

## System Structure

- P1: General principles  
- P2: Revenue management  
- P3: Cost management  
- P4: Partner relations  
- P5: Costing & profitability  
- P6: Financial reporting  
- P7: Internal control  

Total: 51 rules (Điều)
