\# BM-10 – Cost per Course Calculation



\## Purpose

Calculate cost per completed student/course.



\## Key Variables

\- Opening cost

\- Period cost

\- Ending WIP

\- Number of completed students



\## Business Rules

\- Cost per unit = (Opening + Period – Ending) ÷ completed volume

\- Must use validated data from BM-08 and BM-09

\- No calculation without BM-07 completion data



\## System Integration

\- P5: Costing core

\- P6: Financial reporting

\- P3: Cost consolidation



\## Notes

This is the core cost calculation module.
